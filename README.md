# Напоминалка задач (Flutter, Android)

Локальное приложение без сети: задачи на день, календарь «день / неделя», разовые и
регулярные задачи, несколько повторов напоминания, звук с устройства, полноэкранное
напоминание поверх экрана блокировки. Данные хранятся в SQLite на телефоне.

## Сборка

Нужен Flutter 3.38+ (проверено под API плагинов на стабильной ветке 3.47).

```bash
cd task_reminder

# 1. Догенерировать стандартные файлы Android-проекта.
#    Уже существующие файлы (lib/, манифест, MainActivity.kt) НЕ перезаписываются.
flutter create --org kz.reminder --project-name task_reminder --platforms android .

# 2. Включить desugaring, который нужен плагину уведомлений
dart run tool/patch_android.dart

# 3. Зависимости и запуск на подключённом телефоне
flutter pub get
flutter run            # или: flutter build apk --release
```

Готовый APK: `build/app/outputs/flutter-apk/app-release.apk`.

> Важно: `--org kz.reminder` должен совпадать с путём
> `android/app/src/main/kotlin/kz/reminder/task_reminder/MainActivity.kt`.
> Если хотите другой пакет — поменяйте и первую строку `package ...` в MainActivity.kt, и путь к файлу.

## Что умеет

| Функция | Где |
|---|---|
| Календарь неделя ↔ месяц, точки = задачи на день | главный экран |
| Режим «День» — задачи выбранного дня; «Неделя» — все 7 дней списком | переключатель сверху |
| Разовая задача / регулярная: каждый день, по дням недели, каждый месяц, с датой окончания или без | редактор задачи |
| Название и описание | редактор задачи |
| Сколько раз напомнить (1–10) и интервал (1–60 мин) | редактор → «Напоминания» |
| Звук из системного выбора: уведомления, будильники, рингтоны | редактор → «Звук» |
| «Звучать, пока не отреагирую» (звук по кругу) и вибрация | редактор |
| Кнопки в уведомлении: «Выполнено» (гасит оставшиеся повторы) и «Отложить на 10 мин» | шторка |
| Полноэкранное напоминание поверх блокировки | срабатывает само |
| Отметка «выполнено» по каждому дню отдельно | галочка в списке |
| Проверка разрешений и тестовое напоминание | ⚙ Настройки |

## Как устроены напоминания

- Каждое напоминание — точный «будильник» Android (`AlarmManager.setAlarmClock`), он
  срабатывает даже в режиме глубокого сна и переживает перезагрузку телефона.
- Уведомление полноэкранное: если телефон заблокирован — включается экран и открывается
  экран напоминания; если телефоном пользуются — всплывает поверх любого приложения.
- Поверх блокировки приложение показывается **только** при напоминании. После «Выполнено /
  Отложить / Закрыть» оно уходит в фон, остальные задачи без разблокировки не видны.
- Регулярные задачи планируются на 45 дней вперёд (не больше 300 будильников — лимит
  Android ~500). Окно сдвигается при каждом открытии приложения и при каждом действии с
  напоминанием, так что при обычном использовании ничего не теряется.
- Звук на Android 8+ привязан к «каналу» уведомлений, поэтому для каждого выбранного звука
  создаётся свой канал (их видно в системных настройках уведомлений приложения).

## Первый запуск — обязательно

Откройте ⚙ **Настройки** в приложении: все пункты должны быть зелёными. Затем нажмите
**«Проверить напоминание»** и заблокируйте экран — через 15 секунд должно появиться
полноэкранное напоминание со звуком.

На Xiaomi / Huawei / Honor / Oppo / Vivo / Realme дополнительно в настройках приложения
включите автозапуск, «Показывать на экране блокировки», «Всплывающие окна» и снимите
ограничения батареи — иначе прошивка может глушить напоминания.

## Структура

```
lib/
  main.dart                      запуск, обработка нажатий на уведомления
  models/task.dart               задача и расчёт расписания
  data/database.dart             SQLite: задачи и отметки по дням
  state/task_store.dart          состояние + перепланирование уведомлений
  services/notification_service.dart  планирование, кнопки, фоновый обработчик
  services/device_bridge.dart    мост к Kotlin: выбор звука, батарея, блокировка
  screens/home_screen.dart       календарь, день/неделя
  screens/task_edit_screen.dart  создание/редактирование
  screens/alarm_screen.dart      полноэкранное напоминание
  screens/settings_screen.dart   разрешения и тест
android/app/src/main/
  AndroidManifest.xml            разрешения и ресиверы плагина
  kotlin/.../MainActivity.kt     выбор мелодии, показ поверх блокировки
  res/drawable/ic_notification.xml  иконка в строке состояния
tool/patch_android.dart          правка build.gradle.kts (desugaring)
```

Тесты логики расписания: `flutter test`.
